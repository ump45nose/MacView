## requirements.md 的脚本与插件要求

- 命令系统统一承载菜单、快捷键、手势、脚本和插件；绑定存为 JSON。
- 脚本使用 JavaScriptCore，与 HTML 面板共用应用 API，可订阅事件，也可绑定快捷键、菜单和手势。自定义命令支持外部程序或 Shell 模板及文件路径占位符。
- 插件类型包括命令与自动化、HTML/JS 面板、数据源和格式解码/滤镜。JS 插件在 JavaScriptCore/WKWebView 运行，权限写在清单；重活走 stdio JSON-RPC 外部进程；不支持进程内原生插件。
- 用户数据导出/导入范围包含设置、书签、播放列表、显示配置、布局及脚本插件。
- 完整浏览器、下载管理及进程内原生插件不在范围内；RAR/7z 属于不做项。S5-T2 路线图明确解码器插件转入增量。
