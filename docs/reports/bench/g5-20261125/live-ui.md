# G5 真实 App 走查

2026-11-25，MacPro，macOS 27.2（26B123），Asia/Taipei。使用已安装的 Release（S5-F1 产品提交 `8533aaf`）和冻结 main `88793de` 构建的 Debug。下表的「部分」指仅列出的子动作已有实际证据。

## 真实环境与隔离

- 开始时安装版未运行。原支持目录先用 `ditto` 备份至工作区，`diff -qr` 一致。在工作区用 `CFFIXED_USER_HOME` 启动 Release，Foundation 实测支持目录和缓存位置均在独立 home，且应用实际在该处生成 SQLite、Scripts、Plugins、设置与布局。未替换安装版。Debug 用独立 support、cache、layout。
- 所有本地图、zip、插件副本、来源及来源表单输入均为本轮测试数据。本地服务仅监听 127.0.0.1，处理 WebDAV PROPFIND 和 HTTP Range。网络卷只读，未更改挂载与网络。截图仅针对目标应用窗口；只将三张合成夹具的去路径停靠截图作为问题摘要入库，其他截图不入库。
- 刚开始时 Peekaboo 的按需后台宿主没有权限；启动已安装的 Peekaboo.app 后，正式 GUI 桥报告现有录屏、辅助功能与事件合成授权。实际查看了阅读器、面板、设置、错误画面截图，操作了系统菜单、键鼠和应用表单。AX 字样、文件或服务日志以及时间上界分别注明。
