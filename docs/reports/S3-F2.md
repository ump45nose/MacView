## 怎么跑

```sh
make build && APP=build/DerivedData/Build/Products/Debug/MacView.app/Contents/MacOS/MacView
ISO() { echo -MVSupportDirectory $1/support -MVCacheDirectory $1/cache -MVLayoutFile $1/layout.json; }
# 本机自检与截图，浅色、深色各一次
$APP -MVFileOpsSelfTest YES $(ISO /tmp/fo-light) -MVSelfTestOutput build/fileops-screenshots/light -MVAppearance light
# 网络卷：先确认 mount | grep fileops；两步用同一组目录，第一步会自杀（退出码 137）
$APP -MVFileOpsSelfTest net-kill $(ISO /tmp/fo-net); $APP -MVFileOpsSelfTest net-verify $(ISO /tmp/fo-net)
```

网络卷上只建 `macview-selftest-*` 和由 S2 自建自清的 `.macview-trash`；开始前这些名字必须不存在，`net-verify` 结束时只删它们和本机的 `selftest-local`。
