## 架构审核（Astra）

审核范围：仅依据本报告与 `docs/architecture.md`，未读取源码、链接证据或其他文档，未运行验证。**同意“G4 未通过，暂不放行”**；该结论符合 architecture.md §5 按阶段验收判断完成的要求。以下问题需在后续修复和验收中闭环。

1. **透明图片的验收尚未覆盖磁盘缓存这一架构边界。**
   - **问题：** D-S7 已确认透明区显示白矩形，但修复建议仍只笼统列出解码、渲染和缓存。architecture.md §3.3 规定渲染件使用 JPEG，§3.4 又允许从磁盘浏览图直接交付显示；文档未说明含透明通道图片的例外策略。JPEG 无法保留透明通道，这是需要明确的契约缺口；仅凭两份文档不能断定它就是本次白矩形的根因。
   - **影响：** 即使直接解码或复制导出保留透明度，磁盘缓存命中后仍可能显示白底；单次修复后打开同图不足以证明各显示路径一致。
   - **建议：** 定位丢失透明度的具体环节，明确透明图片的渲染件编码或缓存绕过策略，并在架构文档中补齐。复验分别覆盖首次读取、内存命中、重启后磁盘命中及效果开关，确认透明区始终透出所选背景。

2. **视频预览的取消与资源释放契约仍缺真实路径证据。**
   - **问题：** V-S3/G4-13 只确认扫过后预览和翻页可响应，G4-14 尚未完成故障验收。architecture.md §3.2、§3.4 和 §4 要求取消网络视频时切断后续读取、受卷并发限制并在关停时排空工作；同时明确已取齐的帧集和后台拼图不计入在途额度。后者不能由“只有一个鼠标”直接证明没有多个尚未结束的后台写入。
   - **影响：** 画面不冻结和首帧达标不能证明旧请求已停止，也不能证明连续扫过视频后读取或临时内存不会累积；现有 `inFlightBytes` 归零也不代表预览帧集、拼图内存已释放。
   - **建议：** 保留为放行阻塞项。补验快速扫过、移出、关闭预览与退出时的读取回落，区分未取齐请求取消和已取齐后允许完成的缓存写入；同时记录进程内存峰值及稳定后的回落。隔离故障环境就绪后，再核对封面保持、卷降级、恢复和退出行为。不要把尚未验证的资源风险写成已证实的泄漏。

3. **性能待验项缺少符合既定架构的测量闭环。**
   - **问题：** 报告正确拒绝用低帧率截图和独立管线计时代替 GUI 指标，但将 G4-13 列入手动清单，原因包含“Release UI 不暴露队列/帧数计数”，尚未明确如何补证。architecture.md §1、§3.8 已规定性能用 signpost 与 xctrace，调试接口读取现有状态，并提供卷在途读取快照。
   - **影响：** 人工观察同样不能准确判定 1 秒首帧、2 秒取齐和底层取消；若只重复截图或增加正式业务状态用于计时，该项仍无法闭环，或会偏离观测架构。

## 后续：预载翻页一帧内（2026-11-24）

- 根因：命中内存的页也走异步交付。页槽订阅 `image(for:…)` 的流，管线在后台任务里查到缓存后交回主线程；这一跳排在本次翻页触发的布局、标题、页表和图层提交之后，所以「缓存图就绪 → 设图层」等了 10–21 ms。
- 修法：管线新增 `cachedImage(for:target:)`，只查内存，精确尺寸图命中就同步返回（预载图照旧提升到前台解码缓存，也照旧触发派生件补做）。页槽请求图像时先调它：命中就在当前调用里直接设图层，不再发异步请求；未命中照旧走流。接口已同步到 architecture.md §4，并补了单元测试（命中、换滤镜不命中、关停后返回 nil）。
- 证据：Debug 前台 `-MVViewerSelfTest YES`（每次独立的 support、cache、layout 目录）连续 3 次 `SELFTEST OK`。五次翻页依次为 **2.18 / 3.09 / 2.26 / 2.30 / 2.54 ms**、**3.88 / 2.39 / 2.80 / 3.63 / 3.43 ms**、**3.17 / 3.21 / 2.51 / 2.55 / 2.15 ms**，质量均为 exact，门限 8.33 ms 未改。
- 回归：前台 `-MVInputSelfTest viewer`、`-MVVideoPreviewSelfTest viewer`、`-MVSelfTest YES` 均 `SELFTEST OK`。单独运行 `make test` 退出 0。第一次与 Release 构建、自检并行时，`MockPipelineTests.visibleRequestsJumpAheadOfBackgroundOnes` 失败一次（只测 Mock 管线的排队顺序，与本改动无关，负载下偶发）。Release 构建 0 编译警告。
