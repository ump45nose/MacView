# S3-F1：历史、书签、播放列表与虚拟书界面

2026-11-18，`feat/s3-library`，阶段 2 的 W2.6。

## 结论

阶段验收尚未通过。独立验收 `053c4ed` 在可用前台下发现历史被会话恢复写回、书架拖入失败及英文/瀑布流操作缺口。第一轮修复后的实际重启历史检查、拖出数据和占位渲染检查通过；当前系统前台为 `loginwindow`，跨面板真实放下及按钮点击未复验，C2.14 仍未达到 `SELFTEST OK`。最新结果见下方“独立验收后的第一轮修复”；后文保留初次交付的原始证据。

## 实现

- `DockPanels.all` 已在 `30c3b28` 登记历史、书签、播放列表，新面板没有加入默认布局；本次核对后未重复修改登记。
- `-MVLibrarySelfTest YES` 使用真实服务，测试书、图片、视频和 ZIP 均在隔离 support 目录自建；点击、拖放和按键经 `NSApp.sendEvent`。右键菜单取视图的真实菜单后执行菜单动作，播放列表选择器选项后发送其动作，不声称覆盖系统菜单的屏幕点击。设置历史上限通过输入框、回车提交。
- 自检涵盖历史、书签、多级文件夹、面板拖放、列表管理、多选与排序、ZIP/视频虚拟书、阅读设置记忆、删除与撤销、位置迁移、不可用原因、布局保存和调试资料库数据。前台激活前先验证布局和拍空状态截图；无法激活时明确失败退出，不继续产生失真的点击结果。输出逐行刷新，保留首个失败。
- 自检入口接入 `AppDelegate`，并加入测试实例识别及会话隔离：缺少 support/cache/layout 任一隔离参数时沿用现有失败保护，不碰用户会话。
- 调试套接字 `state.library` 返回历史条数及从新到旧的历史、完整书签树、列表 ID/名称/项数/最近用状态；无资料库时为 `null`，读取失败返回错误。
- `Localizable.xcstrings` 初次交付补齐 83 条英文，第一轮修复另补 2 条，包括新命令、三个面板、提示、不可用原因和虚拟书。英文副标题用 “Items: N · Source books: M”，单项时不产生错误复数。
- 规模复核：仅将这 83 条新增本地化压为单行，字典内容完全一致，原有 407 条保留原文和格式；合并单击与拖动后补点击的事件发送代码，保留原有检查和场景。
