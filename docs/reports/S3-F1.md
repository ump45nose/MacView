# S3-F1：历史、书签、播放列表与虚拟书界面

2026-11-18，`feat/s3-library`，阶段 2 的 W2.6。

## 结论

三个面板及 W2.6 的实现已接续，阶段验收尚未通过。资料库自检在中英文两轮均无法取得前台，C2.14 的 `SELFTEST OK` 尚未满足；完整交互截图、三千项流畅度和网络卷实测仍待验收。编译及 Core 测试通过不能代替这些检查。

## 实现

- `DockPanels.all` 已在 `30c3b28` 登记历史、书签、播放列表，新面板没有加入默认布局；本次核对后未重复修改登记。
- `-MVLibrarySelfTest YES` 使用真实服务，测试书、图片、视频和 ZIP 均在隔离 support 目录自建；点击、拖放和按键经 `NSApp.sendEvent`。右键菜单取视图的真实菜单后执行菜单动作，播放列表选择器选项后发送其动作，不声称覆盖系统菜单的屏幕点击。设置历史上限通过输入框、回车提交。
- 自检涵盖历史、书签、多级文件夹、面板拖放、列表管理、多选与排序、ZIP/视频虚拟书、阅读设置记忆、删除与撤销、位置迁移、不可用原因、布局保存和调试资料库数据。前台激活前先验证布局和拍空状态截图；无法激活时明确失败退出，不继续产生失真的点击结果。输出逐行刷新，保留首个失败。
- 自检入口接入 `AppDelegate`，并加入测试实例识别及会话隔离：缺少 support/cache/layout 任一隔离参数时沿用现有失败保护，不碰用户会话。
- 调试套接字 `state.library` 返回历史条数及从新到旧的历史、完整书签树、列表 ID/名称/项数/最近用状态；无资料库时为 `null`，读取失败返回错误。
- `Localizable.xcstrings` 补齐本阶段 83 条英文，包括新命令、三个面板、提示、不可用原因和虚拟书。英文副标题用 “Items: N · Source books: M”，单项时不产生错误复数。
- 规模复核：仅将这 83 条新增本地化压为单行，字典内容完全一致，原有 407 条保留原文和格式；合并单击与拖动后补点击的事件发送代码，保留 78 处检查和全部场景。

## 串通修改与原行为变化

保留并接续了前任的五个已修改文件和 `LibrarySelfTest.swift`。跨工作包的小修只有 `CollectionView`：失败条目的列表行不再取缩略图，也不等待其缩略图完成，避免虚拟书不可用页继续显示缓存旧图。这与网格和查看器的占位逻辑一致。未改 `Packages/`，未增加依赖，未删除已有功能；Release 不包含自检及调试接口。

## 未通过原因与后续

- 一次复用了已改动布局的隔离目录，额外触发三项初始布局断言失败；随后用全新目录复跑。该次日志另存为 `library-zh-light-reused-layout.log`，不作为功能失败或通过的证据。
- 更早的一次试跑没有留下 `SELFTEST` 汇总，stdout 为空，仅有部分截图和 stderr（`library-zh-light.log` / `.stderr`）；退出原因未确认，不计为通过。随后将资料库自检改为逐行刷新输出，并保留 `library-zh-light-2.log` 中实际发生的失败。
- 自检使用 `open -n`、`-MVSelfTestActivate YES` 并对测试窗口请求置前，仍始终 `NSApp.isActive == false`。系统前台登记为 `UserNotificationCenter`；桌面自动化不能访问该系统应用，无法确认是锁屏还是系统提示。未关闭用户实例，也未绕过系统授权。恢复可用前台后，重跑中英文资料库自检；首轮失败不能用之后的 Core 通过覆盖。
- App 重启后历史、书签、播放列表和新面板布局的保持；拖到面板标签上停留约 0.35 秒切换；三千项 UI 流畅度；完整占位页、视频、确认面板及改名状态的设计对照仍需验收。持久化单元测试仅作为补充证据。
- 网络卷 `fileops-a` / `fileops-b` 的 S1、S8、S10 按阶段约定留整体验收，由用户挂载/卸载；本轮未修改 NAS 配置、挂载或用户图片。
- 阶段 1 总结保留的 C1.16 慢锁关闭超时问题未在本阶段改动。
