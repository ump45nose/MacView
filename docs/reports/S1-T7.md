# S1-T7 MVSettings 与 MVCommands

## 设置（W1.3）

### 实现

- `JSONDocumentStore<Value>` 使用 `version`/`value` 外层格式；不存在的文档只在第一次修改时写出。更新使用同目录临时文件与原子替换，串行处理修改与外部重载。
- 目录监听负责原子替换，文件监听负责原地修改；50 ms 去抖后重载。非法 JSON、类型错误与未来版本保留上一份可用值，错误包含行列位置；启动时的错误保留到订阅后交付。
- `FileSettingsStore` 组合 `settings.json`、`path-rules.json`；全局层缺少字段时递归补入默认值并报告，不自动改写用户文件。路径规则复用 `Location.hasPrefix`，按具体程度及文件顺序逐字段合并，最后应用书记忆。
- `state.sqlite` 用 GRDB、WAL 与完整同步；Location 的结构化 JSON 作主键。启动读取已有书记忆；后续保存先在内存按书合并，每 250 ms 用事务批量写出。`flush()` 等待写入并向调用者抛出错误，失败批次保留且期间的新值优先。
- 删除 `SettingsChange.keyBindings`；现有 Mock 无此分支，未作修改。`SettingsStore` 协议签名保持不变。
- `mvtest-writer settings <目录>` 持续更新真实设置，供 SIGKILL 测试使用。
