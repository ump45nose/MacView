## 设置（W1.3）

### 实现

- `JSONDocumentStore<Value>` 使用 `version`/`value` 外层格式；不存在的文档只在第一次修改时写出。更新使用同目录临时文件与原子替换，串行处理修改与外部重载。
- 目录监听负责原子替换，文件监听负责原地修改；50 ms 去抖后重载。非法 JSON、类型错误与未来版本保留上一份可用值，错误包含行列位置；启动时的错误保留到订阅后交付。
- `FileSettingsStore` 组合 `settings.json`、`path-rules.json`；全局层缺少字段时递归补入默认值并报告，不自动改写用户文件。路径规则复用 `Location.hasPrefix`，按具体程度及文件顺序逐字段合并，最后应用书记忆。
- `state.sqlite` 用 GRDB、WAL 与完整同步；Location 的结构化 JSON 作主键。启动读取已有书记忆；后续保存先在内存按书合并，每 250 ms 用事务批量写出。`flush()` 等待写入并向调用者抛出错误，失败批次保留且期间的新值优先。
- 删除 `SettingsChange.keyBindings`；现有 Mock 无此分支，未作修改。`SettingsStore` 协议签名保持不变。
- `mvtest-writer settings <目录>` 持续更新真实设置，供 SIGKILL 测试使用。

## 命令（W1.4）

### 实现

- `BindingResolver` 解析单键与多键序列，默认续键超时 1 秒；返回 `pending` 供 App 提示。当前作用域的序列前缀优先于全局，`textInput` 只匹配显式声明的文本作用域绑定。超时、作用域变化与续键失配清除待定序列；失配的键重新作为首键解析。
- `BindingResolver.conflicts(in:)` 返回同一作用域里的相同序列与前缀冲突，每对一次；跨作用域不算冲突。
- `KeyBindingsFile` 是 `keybindings.json` 的 value 类型，与 SettingsStore 分开；`KeyBinding.effective` 以命令 ID 为单位用用户绑定替换全部默认绑定。空序列可取消该命令的默认绑定，不参与按键解析与冲突检测。
- `CoreCommands.all` 提供 51 个 P0 命令，每项有独立 `CommandID` 常量、中文 `LocalizedStringResource` 标题（`.main` bundle）、分类和默认绑定。覆盖翻页、书、四种浏览方式、单双页/方向/宽页、全部缩放模式及仅缩小、排序/递归、窗口/面板、重试与设置。
- 菜单与命令清单共用分组来源，生成「文件、显示、翻页、书、窗口」五棵菜单树，避免两份清单分别维护。关闭窗口继续由 App 原生命令处理。
- 参考本机 `Others/NeeView/NeeView/Command/Commands/` 的 `ShortCutKey` 定义。适配 macOS 后采用 ⌘O、⌘N、⌘T、⌘,、⌃⌘F 等组合；查看器中方向键/空格按帧翻页，⌥方向键按页或切书，`g g`/`g e` 到首页/末页。逻辑键名使用小写字母与 `Space`、`Right` 等名称，由 App 的 InputRouter 转换。
