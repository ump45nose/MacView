# S2-F2 集合组件与面板

2026-11-03，MacPro，分支 `feat/s2-p0`。

## 做了什么

- `App/Collection/`：`CollectionView`（列表、表格用 NSTableView，网格、瀑布流用 `CanvasView`）、`CollectionPanel`、`BookshelfPanel`、`PageListPanel`。删除 `App/Dock/PlaceholderPanel.swift`；`DockSelfTest` 改用正式面板。
- 面板的样式、尺寸、排序各自存在 `layout.json`；页面列表的排序只改显示，不改翻页顺序；书架的排序决定相邻书。
- `DockAreaView` 的区头只有一个 ⋯ 菜单。
- 公开 `ReadingOrder.sorted`（阶段文档写的 `ReadingListing.sorted` 在代码里叫这个名字）。
- 自检：`-MVPanelSelfTest`。

## 证据

- `-MVPanelSelfTest`：屏幕解锁时 `SELFTEST OK`。屏幕锁定时 App 成不了前台，行点击和浮动面板切换改走直接调用，并打 INFO。
- `-MVDockSelfTest main`、`restore`、`corrupt`：通过。

见 `docs/design/README.md` 的阶段 2 偏差。
