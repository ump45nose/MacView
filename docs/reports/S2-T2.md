# S2-T2 性能验收工具与证据

验收脚本经 Debug 本地套接字驱动以 `open -n` 启动的独立实例，使用隔离的 support、cache、layout 和绝对套接字路径，按 PID 管理；每个场景写 `bench/S2-T2-<场景>.json`，其中 `budget`、`measured`、`verdict` 分别记录预算、实测、判定。样本为零时不得判为通过。最终功能冻结在 `3e417a1`，13 份正式 JSON 均标记此提交，结果为 4 项通过、2 项未通过、7 项未验证。修改前对照保存在 `bench/before-w35/`，W3.5 初次运行保存在 `bench/w35-initial/`，不混入最终结果。

## 真实输入录制（C5.2、C5.12）

先解决上述 xctrace 原始 spool 的工作区隔离问题，再在内建屏 120 Hz、屏幕解锁、窗口前台的条件下由用户操作；自动场景和 smoke 均不能替代真实输入验收。以下命令在工作区根目录执行，输出目录须不存在，trace 保留在工作区且不入库。设置 `TMPDIR` 只是指定普通临时文件位置，当前不能控制 xctrace 原始 spool。

```sh
mkdir -p "$PWD/build/acceptance/user-tmp"
export TMPDIR="$PWD/build/acceptance/user-tmp"
scripts/acceptance/record-trackpad.sh scroll-cached build/acceptance/user-scroll-cached
scripts/acceptance/record-trackpad.sh scroll-cold build/acceptance/user-scroll-cold
scripts/acceptance/record-trackpad.sh scroll-cached build/acceptance/user-dock-drag
scripts/acceptance/record-trackpad.sh scroll-cached build/acceptance/user-dock-resize
```

前两段各用触控板快速来回滚动、甩动惯性和停走 60 秒；后两段分别反复拖动面板标签到各停靠区、拖动停靠区和上下分割的分隔线 60 秒。检查各目录 `hitches.json` 和 `during.json`，记录帧数、卡顿数及帧时间 P99，预算 ≤ 8.33 ms。C5.2 还要求四种画布布局分别滚动与改尺寸，步骤及锚点目视检查见 [S1-F3 报告](S1-F3.md#给用户的录制步骤c52)。
