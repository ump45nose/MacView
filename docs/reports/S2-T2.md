## 内存与停顿

本轮 1800 组物理占用、常驻内存、时间、分层和前台样本对应，采样错误 0；2399 次 state 均在前台。物理占用由外部 `proc_pid_rusage(RUSAGE_INFO_V4).ri_phys_footprint` 取得，300 秒后的 60 秒滚动中位数最大偏差 1.536002%，总中位数 1,389,866,320 字节，每秒最大偏差 1.613215%，峰值 2,486,472,856 字节。常驻内存滚动中位数最大偏差 1.401649%，总中位数 1,721,802,752 字节，峰值 2,751,299,584 字节。1800 个动作，state 最大往返 14.564167 ms，无超时或停顿。leaks 的 416 项、19,936 字节均来自允许的 3 个 `com.apple.linkd.autoShortcut` 根（139、139、138 项），意外根为 0；leaks 返回码 1 由已允许的系统根产生。三个分项和完整场景均通过。

第五轮对照运行 1800.005 秒，物理占用滚动偏差 1.743218%、意外泄漏 0，但 11 次 state 停顿、最大 3123.189 ms，完整场景当时失败；原始数据见 [归档](bench/before-occlusion/S2-T2-memory-30min.json)。唯一自动 sample 在停顿约 3 秒时启动，state 随后约 0.123 秒返回，可能多数采到恢复后，不能据此确认 CA flush 是根因。第五轮 `scroll` 反复抬起窗口，旧数据只能证明 App 离开前台且用户使用电脑，不能证明持续被遮挡。独立遮挡实验结果及未测因素见 [S2-T3](S2-T3.md)。

## 脚本修正与 NAS 离线排查

第五轮实测后的历史脚本修正：`ac5b10c` 将滚动判定改为只看帧时间 P99 ≤ 8.333 ms，hitch 时长、频率和最长帧保留为诊断；settle 独立录制 60 秒，按每滚 2 秒停 0.5 秒共 24 轮。入口保留显式场景顺序，仅将 memory 放末尾；默认顺序把 NAS 放在录制前。执行方报告纯校验 98 项、Python 语法、shell 语法及 diff 检查通过；stdin 合成节奏、独立 settle 入口、无 lastDisplay 的初始 exact、4 场景显式和默认顺序检查通过，当时没有实跑新场景或保存 raw。

`ef5d933` 将 NAS 初始就绪判断改为 `wait_exact(..., prime=True)` 读取实际 `pageSlots`。旧 `wait_frame` 依赖用于翻页计时的 `lastDisplay`，静态调用链显示初始就绪存在竞态；旧失败没有 `lastState`，不能将其说成已动态证实的原因。未发现预热提前退出的证据：现有缩略图预取路径会等待衍生件，不据此推断所有缓存实际命中；当时没有修改预热逻辑；本轮已实跑注入，结果见上表。静态核对确认 `fault_volumes` 用本地挂载路径筛选 root，而 DebugSocket 的网络 root 来自 `Location.description`，显示远端 share，两者不相容，可能使记录被筛空；运行时原始 volumes 未保存，不能反推实际在途数。故障期间约 10 秒报错、恢复后生成衍生件支持发生等待，也不能证明每次的在途读取。

## 用户真实输入录制（C5.2、C5.12）

C5.2、C5.12 的真实输入录制及占位符真实比例、加载后不跳动仍待确认。下列步骤保留供人工验收使用。

手动录制时解锁屏幕并让窗口前台可见，前后刷新率均须 ≥ 119 Hz。录前快照系统临时目录现有的 `instruments*.ktrace`，确认数据卷可用空间 ≥ 60 GB；汇总后检查 `lsof`，只清理本次新增且未被占用的 raw。自动场景 `.trace` 汇总后删除，用户手动录制的 `.trace` 保留。

录制脚本固定使用 `build/DerivedData-profile/Build/Products/Debug/MacView.app`，缺失时会自动构建。使用前先检查目标路径：不存在时用 `ditto outputs/stage3-frozen/MacView.app build/DerivedData-profile/Build/Products/Debug/MacView.app` 原样复制；已存在时先核对，不覆盖不匹配的 bundle。用 `shasum -a 256` 核对主二进制，用 `codesign -dv --verbose=4` 核对 cdhash，均须与 `outputs/stage3-frozen/manifest.json` 及本文身份一致。

在工作区根目录执行以下命令，分别使用新的输出目录：

```sh
scripts/acceptance/record-trackpad.sh scroll-cached build/acceptance/user-scroll-cached
scripts/acceptance/record-trackpad.sh scroll-cold build/acceptance/user-scroll-cold
scripts/acceptance/record-trackpad.sh scroll-cached build/acceptance/user-dock-drag
scripts/acceptance/record-trackpad.sh scroll-cached build/acceptance/user-dock-resize
```

前两段各用触控板快速来回滚动、甩动惯性和停走 60 秒；后两段分别反复拖动面板标签到各停靠区，以及拖动停靠区和上下分割的分隔线 60 秒。检查各目录的 `hitches.json` 和 `during.json`，记录帧数、卡顿数及帧时间 P99；有效 120 Hz 下只按帧时间 P99 ≤ 8.333 ms 判定，卡顿及提交、渲染用时作诊断。C5.2 还要求四种画布布局分别滚动与改尺寸，步骤和锚点目视检查见 [S1-F3 报告](S1-F3.md#给用户的录制步骤c52)。
