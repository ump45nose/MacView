# S2-T1 预取策略与 NAS 调优

## 偏差

`PageFrameFit` 用 `FittedPage` 保存每页布局像素，因为元素元组不能作为 Hashable 存储属性。`maxDecodeLongSide` 不进 `fit` 的参数；`displayTargets` 用 `PixelSize.fitting(longSide:)` 压长边，滤镜和锐化取 `ResolvedBookSettings`。半页的显示目标是该半幅的像素尺寸，管线按整页身份解码到这个尺寸。
