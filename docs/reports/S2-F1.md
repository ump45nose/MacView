# S2-F1 查看器

2026-11-03，MacPro（M1 Pro，macOS 27.0.1），分支 `feat/s2-p0`。屏幕刷新率这台机器当时是 60 Hz。

## 做了什么

- `App/Viewer/`：`ViewerContainerView` 按浏览方式切换，`PagedViewerView` 负责单双页、全部缩放模式、设备像素 1:1、放大镜、翻页保持缩放、导航图；`ContinuousViewer` 包 `CanvasView`，做纵向、横向连续和瀑布流；`TiledPageLayer`、`AnimatedPageLayer`、`VideoPageView`。删除 `App/Reader/PageView.swift`。
- Core：`PageFrameFit` 分开布局尺寸和解码尺寸，`ContainerProvider.fileLease` 替换 `fileURL`，`ViewerTransform`。
- 自检：`-MVViewerSelfTest`，事件走 `NSApp.sendEvent`。

## 证据

- `-MVViewerSelfTest`：屏幕解锁时 `SELFTEST OK`。
- C2.4 翻页到上屏 2–10 ms（60 Hz 屏，自检内统计）；120 Hz 未测。
- C2.8 分块移动：丢弃 5 块，取消 0 个在途请求。

## 偏差

- `PageFrameEngine` 本来就把元素从左到右排，阶段文档说要改的地方不用改。
- `reloadSettings()` 没有加：`settingsChanged()` 已保持当前页。
- 额外公开：`ReaderSession.currentPage`、`maxDecodeLongSide`、`neighborSort`、`lastMoveAt`。`ExtractStore.install` 加 `pathExtension`，视频要靠扩展名识别。
- `zoom < 1` 时目标按 zoom 为 1 解码；视频页不做鼠标平移。
- Debug 下开了自检或调试接口时关响应式滚动（见架构 §3.8）。阶段 3 量帧时间要注意。
- 其余显示偏差见 `docs/design/README.md`。

## 未决

- 捏合和惯性滚动手感、视频声音、NAS 实际操作、菜单打开时的显示要用户手测。
- 帧时间、内存、NFS 归阶段 3。
