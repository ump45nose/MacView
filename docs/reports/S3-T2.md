## 与规格的偏差和未决事项

- 第 3 轮设计答复将 Finder 默认快捷键改为 viewer、list 的 ⌥⌘R，viewer 的 ⇧⌘R 保持递归；定向测试已核对。
- 临时名使用传输 ID 前 8 位，记录持久化冲突策略；恢复只按大小和 SHA-256 比对，目标不匹配或无法读取时不删源，并按原策略重做。创建后无缓存设置失败、写入或校验失败及取消会尝试清理；清理失败保留移动记录。`temporaryCreationFailureCleansOrRetainsJournal` 在服务层模拟创建后设置失败并覆盖清理失败及恢复；底层实际设置失败由 C1.5 的测试注入验证。
- 旧式临时项存在时无法证明其归属，恢复计入 pending，保留源、目标、临时项及记录；旧式临时项不存在且需要重做时，先将带 ID 的新临时位置写入记录。新记录先写后排他创建；如果临时名碰撞，报 EEXIST 后、删除记录前崩溃，或删除记录失败，恢复仍可能把他人的同名项当临时项删除。`temporaryNameCollisionDoesNotDeleteOrRetry` 只覆盖未崩溃且记录删除成功的情况，不证明上述边界安全。
- 已删源但尚未删除记录时，恢复无法与源核对：即使正式目标存在，也会保留目标、删除记录并计入失败。`recoveryWithMissingSourceCannotVerifyExistingTarget` 覆盖该结果；因此崩溃发生在这一区间时报告可能是失败，不应据此认定目标丢失。
- NFS 排他改名回退普通改名时，目标检查与改名之间存在设计上接受的竞态；SMB 的排他改名和系统废纸篓行为没有实测。文件修改时间会保留，目录自身修改时间不保留；跨卷复制不保留扩展属性。
- 符号链接的同卷操作及永久删除按链接本身处理；复制和跨卷移动拒绝链接。`symbolicLinksAreNotFollowed`、`linksAndUnknownRegularFilesFollowFileOperationRules` 及本机／辅助进程读取测试通过。
- 真实网络验收和 `make test` 待运行；App 的实际界面、交互及用户验收不属于本阶段证据。
