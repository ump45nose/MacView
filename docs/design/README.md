# MacView 界面设计稿

- 画布：[MacView 设计画布](https://claude.ai/artifact/Ne5Dp8nB253cBvKDUT1u2v)。claude.ai 的 Design 类型，私有，2026-10-31 第 10 版。
- 状态：方向已由用户确认（S0-F2）。稿中的数值和文案都是示例；实现时遵循本文的规则和 [architecture.md](../architecture.md)。
- 源文件：各画板的源文件在画布的 `project/` 目录下，例如 `project/Main.dc.html`。令牌、字体、间距、圆角、控件和图标都定义在“设计基础”画板里。

## 方向：纸面与暗房

- 配色：
  - 整理类界面用浅色 Ivory，包括主窗口、集合视图、状态和设置。
  - 阅读类界面用暖色 Slate 深色，包括双页、单页、竖条和横条。
  - 除“设计基础”外，每张画板都可以切换浅色和深色。
  - 配色参考了 Anthropic 的视觉语言（Ivory、Slate、Clay），没有使用它的字体和标志。
- 字体全部是系统字体：
  - 衬线：New York / 宋体，用于书名、标题和空状态。
  - 无衬线：SF Pro / 苹方。
  - 等宽：SF Mono。
- 尺寸按 macOS 指针设备的 HIG，控件高 22–30 px。
- 对比度规则：
  - 浅色模式下不用 Clay 色的文字；主按钮用 Slate 底配 Ivory 字。
  - `--accent-text`：浅色为 #141413，深色为 Clay。
  - 危险色：浅色 #A33B2A，深色 #F09C8B。
  - text-3 只放在 ground 或 raised 背景上。

## 画板

| 画板 | 内容 |
|---|---|
| 主窗口 · 瀑布流 | 可交互：拖缩略图尺寸滑块改变列数；点图块进入双页 |
| 阅读 · 双页与单页 | 可交互：翻页、右开/左开、首页单页、宽页的原样/单独/拆分、7 种缩放、放大镜、导航图 |
| 阅读 · 竖条与横条 | 章末接下一话；横条右开 |
| 设计基础 | 令牌、字体、间距与圆角、控件（浅色和深色）、44 个图标 |
| 集合视图与停靠 | 列表、详情表格、网格、瀑布流，排序菜单，三种停靠示例 |
| 状态与反馈 | 见表下 |
| 设置窗口 | 可交互，见表下 |

“状态与反馈”画板包括：
- 卷响应缓慢（degraded）与卷不可用。
- 单项加载失败。
- 定位到第 k 页。
- 大目录内容渐进出现。
- gz 解压中。
- 空状态。
- 多键序列。
- 配置解析失败。
- 视频页。

“设置窗口”画板：
- 分为浏览、显示、缓存、路径规则四页。
- 缓存预算按 architecture.md §3.4。
- 路径规则可以切换规则、改名、移除覆盖项，并实时显示每个值继承自哪里（全局 → 父规则）。

## 实现约定

- 稿中手绘的图标，实现时换成 SF Symbols。
- 以下示例值都不是定稿：
  - 用量与吞吐、NAS 名称与路径。
  - 解码上限 8192 px、锐化 0.4。
  - 多键序列 G G / G E / G B。
- 设置窗口不含快捷键编辑，这是 P1 功能（S4-F2）。P0 只提供 `keybindings.json` 和解析失败时的提示。
- 画布没有经过渲染验证，布局和高度都是估算的。实现时以实际渲染为准，出现偏差就更新本文。

## 实际渲染与画布的偏差

来源是 S1-F1、S1-F2、S1-F3 的报告和自检截图（2026-11-01，Mock 服务）。其余画板还没有实现，不在此列。

- 工具栏：只有上一本、下一本两个按钮，加上书名（衬线 17/500）和路径。画布上的停靠区开关目前在“显示”菜单和区头按钮里；浏览方式、排序、缩略图尺寸属于 S2。
- 跳页：画布没有画，实现为状态栏内的页码输入框（⌘G），不另开弹出层。
- 状态栏：右侧标明“Mock 服务”，接入真实服务（S1-T8）之前都有。
- 停靠区：画布没有画折叠形态。实现中折叠就是隐藏，区不占空间，没有只剩标题条的形态。
- 放置指示：画布只画了放到边缘的整区浅 Clay 区域。实现补了标签之间的竖线和分割位置的横线；整区指示盖在已有内容之上。
- 配置解析失败的提示条：画布上是“第 N 行有语法错误，仍在使用上一份可用的配置”。`layout.json` 解析失败时实际是用默认布局，所以文案是“已改用默认布局”，并写明行列和“调整布局后会覆盖这个文件”。
- 多键序列的待定提示：只列出实际绑定的后续键（G 首页、E 末页），没有画布示例中的 B。

以下偏差不修（2026-11-02，阶段 5 验收后决定）：

- 页码输入框的焦点环用系统强调色，不用 Clay。
- 窗口标签栏用系统原生样式，画布没有定义。
- 浮动面板用系统 NSPanel 的标题栏。
- 区头用“分割”“隐藏”两个按钮代替 ⋯ 菜单，⋯ 菜单留给 S2-F2。
- 空状态的虚线框和“最近打开”归 S2-F3。
