# MacView 界面设计稿

- 画布：[MacView 设计画布](https://claude.ai/artifact/Ne5Dp8nB253cBvKDUT1u2v)。claude.ai 的 Design 类型，私有，2026-10-31 第 10 版。
- 状态：方向已由用户确认（S0-F2）。稿中的数值和文案都是示例；实现时遵循本文的规则和 [architecture.md](../architecture.md)。
- 源文件：各画板的源文件在画布的 `project/` 目录下，例如 `project/Main.dc.html`。令牌、字体、间距、圆角、控件和图标都定义在“设计基础”画板里。

## 方向：纸面与暗房

- 配色：
  - 整理类界面用浅色 Ivory，包括主窗口、集合视图、状态和设置。
  - 阅读类界面用暖色 Slate 深色，包括双页、单页、竖条和横条。
  - 除“设计基础”外，每张画板都可以切换浅色和深色。
  - 配色参考了 Anthropic 的视觉语言（Ivory、Slate、Clay），没有使用它的字体和标志。
- 字体全部是系统字体：
  - 衬线：New York / 宋体，用于书名、标题和空状态。
  - 无衬线：SF Pro / 苹方。
  - 等宽：SF Mono。
- 尺寸按 macOS 指针设备的 HIG，控件高 22–30 px。
- 对比度规则：
  - 浅色模式下不用 Clay 色的文字；主按钮用 Slate 底配 Ivory 字。
  - `--accent-text`：浅色为 #141413，深色为 Clay。
  - 危险色：浅色 #A33B2A，深色 #F09C8B。
  - text-3 只放在 ground 或 raised 背景上。

## 画板

| 画板 | 内容 |
|---|---|
| 主窗口 · 瀑布流 | 可交互：拖缩略图尺寸滑块改变列数；点图块进入双页 |
| 阅读 · 双页与单页 | 可交互：翻页、右开/左开、首页单页、宽页的原样/单独/拆分、7 种缩放、放大镜、导航图 |

| 集合视图与停靠 | 列表、详情表格、网格、瀑布流，排序菜单，三种停靠示例 |
| 状态与反馈 | 见表下 |
| 设置窗口 | 可交互，见表下 |

“状态与反馈”画板包括：
- 卷响应缓慢（degraded）与卷不可用。
- 单项加载失败。
- 定位到第 k 页。
- 大目录内容渐进出现。
- gz 解压中。
- 空状态。
- 多键序列。
- 配置解析失败。
- 视频页。

“设置窗口”画板：
- 分为浏览、显示、缓存、路径规则、文件五页（“文件”页由 S3-F2 加入）。
- 缓存预算按 architecture.md §3.4。
- 路径规则可以切换规则、改名、移除覆盖项，并实时显示每个值继承自哪里（全局 → 父规则）。

## 实现约定

- 稿中手绘的图标，实现时换成 SF Symbols。
- 以下示例值都不是定稿：
  - 用量与吞吐、NAS 名称与路径。
  - 解码上限 8192 px、锐化 0.4。
  - 多键序列 G G / G E / G B。
- 设置窗口不含快捷键编辑，这是 P1 功能（S4-F2）。P0 只提供 `keybindings.json` 和解析失败时的提示。
- 画布没有经过渲染验证，布局和高度都是估算的。实现时以实际渲染为准，出现偏差就更新本文。

## 实际渲染与画布的偏差

来源是 S1-F1、S1-F2、S1-F3 的报告和自检截图（2026-11-01，Mock 服务）。其余画板还没有实现，不在此列。

- 工具栏：有左右停靠区开关、上一本、下一本，加上书名（衬线 17/500）和路径。浏览方式、排序、缩略图尺寸属于 S2。
- 跳页：画布没有画，实现为状态栏内的页码输入框（⌘G），不另开弹出层。
- 状态栏：右侧标明“Mock 服务”，接入真实服务（S1-T8）之前都有。
- 停靠区：画布没有画折叠形态。实现中折叠就是隐藏，区不占空间，没有只剩标题条的形态。
- 放置指示：画布只画了放到边缘的整区浅 Clay 区域。实现补了标签之间的竖线和分割位置的横线；整区指示盖在已有内容之上。
- 配置解析失败的提示条：画布上是“第 N 行有语法错误，仍在使用上一份可用的配置”。`layout.json` 解析失败时实际是用默认布局，所以文案是“已改用默认布局”，并写明行列和“调整布局后会覆盖这个文件”。
- 多键序列的待定提示：只列出实际绑定的后续键（G 首页、E 末页），没有画布示例中的 B。

以下偏差不修（2026-11-02，阶段 5 验收后决定）：

- 页码输入框的焦点环用系统强调色，不用 Clay。
- 窗口标签栏用系统原生样式，画布没有定义。
- 浮动面板用系统 NSPanel 的标题栏。
- 区头只有一个 ⋯ 按钮，分割、移动、浮动和隐藏都在菜单里（S2-F2）。
- 空状态的虚线框和“最近打开”没有做：“最近打开”依赖 P1 的历史。

阶段 2（S2-F1、S2-F2、S2-F3）实际渲染与画布的偏差：

- 图标用 SF Symbols，不用画布上的线条图标。
- 瀑布流和竖条的轨道：竖条用系统滚动条，不用画布的右侧页码轨道；页码标签在右下角。条之间没有间距，占满宽度。
- 瀑布流底部没有“继续向下滚动进入下一话”的自动切书，末尾只显示下一本的入口。
- HUD 在指针距底边 180 点以内时自动显示。
- 面板：面板内部的头部不重复面板名（标签上已有）；网格的文字盖在缩略图上（画布在下方）；尺寸滑块是连续的 60–360，不是 1–6 档。
- 书架列表的详情是“文件夹/压缩包 · 大小 · 读到第 N 页”，没有页数和“已读完”：要枚举 NAS 才知道。
- 单击打开书，双击进入文件夹。
- 设置：缓存页没有用量和“清除…”，Core 没有对应接口。路径规则的路径用 `Location` 的字符串，没有做面包屑。
- 卷状态：画布的卷响应缓慢是主区里的条，实现把它放在窗口顶部，和配置错误条排在一起；`unavailable` 在书已打开时也是这条，书打不开时才是查看器中央的提示。
- 表格：表头用系统样式，没有 6 px 内边距和排序箭头，有列分隔线。
- 网格和瀑布流的选中环只有 2 px 的 Clay，没有 ground 间隙。
- 主区瀑布流的图块没有页码胶囊和当前页环。竖条和横条的胶囊没有“· 100%”，横条没有“横条 · 右开”和范围页码。
- 状态栏只有页码和尺寸，没有文件大小、已缓存进度和卷状态；卷状态显示在窗口顶部的条上。
- 英文下窗口较窄时，工具栏放不下的全屏和右侧开关收进 `>>`。

文件操作（S3-F2，对照需求期间的设计稿画板 1–6，2026-11-14 用户确认，原型未入库）实际渲染与设计稿的偏差：

- 分类面板：作为停靠面板时不在面板内部工具栏重复放置 `⋯` 按钮，“清空回收目录…”集成在停靠区头的 `⋯` 菜单中；底部提示文字排在“+ 新建目标并移入”按钮上方；空状态的“添加目标…”按钮排在标题与说明上方，标题用无衬线粗体。
- 右键菜单：使用系统原生 `NSMenu`，样式随系统；“用指定应用打开”子菜单中默认应用显示为“预览（默认）”并带应用图标。自检截图里的菜单是按真实菜单项画出来的示意，不是系统渲染。
- 设置 · 文件：顶部页签栏中“文件”页签不带设计稿示例中的“新”字角标，与其余四个设置页签样式一致。

搜索与元数据（S3-F3）实际渲染与设计稿的偏差（2026-11-19，阶段 2，对照 `.spec/mockups/search.html`）：

- 搜索栏与筛选条：使用 AppKit 原生 `NSSearchField`（支持最近 10 个搜索词下拉）与三个 `.recessed` 样式的 `NSPopUpButton`（评分、标签、类型），替代原型中的自定义圆角输入框和胶囊筛选按钮；标签清除通过菜单内“清除标签”项操作，不在按钮上单独绘制内嵌清除叉号。
- 建立索引进度横幅：复用 `FileOperationBanner` 边框与 `FlatButton` 风格，使用系统条形 `NSProgressIndicator`；第二步进度显示“已探测 / 待探测 张”（不含估算剩余时间）；完成后约 2.5 秒自动收起。
- 搜索结果行：使用原生 `NSTableView`；匹配词高亮采用粗体配 `Theme.accentSoft` 背景色（原型为透明背景配强调色文字）；不可用条目复用 `LibraryAvailability` 的灰显与右侧 `UnavailableBadge` 图标，并在副标题行显示“⚠ 网络卷没有连接”，点击后经底部状态栏给出短提示。
- 批量写入进度：批量评分与标签的 `n / 总数` 进度与“取消”按钮复用窗口底部状态栏进度条，并配合查看器底部的 `MetadataToastView` 悬浮提示，不占用书架搜索结果底栏。
- 信息面板：默认不进入初始停靠布局，经 `⌥⌘I` 或停靠区 `⋯` 菜单打开；评分星标采用可点击 `NSButton`（再次点击当前星数清零），标签以带 `×` 的 `FlatButton` 呈现，不使用虚线边框；写入失败区采用 `Theme.dangerSoft` 底色配原生“重试”按钮。
- 标签编辑弹层（⌥T）：使用系统 `.transient` `NSPopover`，含输入框、建议列表（多选时以 `✓` / `–` 区分全部/部分命中）和“取消”按钮；回车或单击建议行直接提交并关闭，不另设“完成”主按钮。

显示配置与基础调色（S4-F1）实际渲染与小样的偏差（2026-11-20，阶段 3，对照 `.spec/mockups/effects.html`）：

- `profiles.json` 解析错误：统一由窗口顶部现有的 `FileErrorBanner` 显示错误信息与“打开文件”入口（与 `settings.json`、`path-rules.json`、`keybindings.json` 一致），不在效果面板顶部重复显示第二条错误条；面板列表保留上一份可用配置，文件修好后自动重载并清除错误条。
- 删除配置：在行尾 `⋯` 菜单点“删除”后以窗口 sheet 确认（“删除“名称”？”），确认后直接删除，不借窗口撤销管理器提供撤销。
- 控件与标签：调色开关、滑块、背景色块自定义取色器与弹出层使用 AppKit 原生 `NSSwitch`、`NSSlider`、`NSColorPanel` 与 `.transient` `NSPopover`；配置行内的组标签使用精简短名（浏览、缩放、效果、背景），避免窄面板与英文下截断。

输入与自定义设置三页（S4-F2 阶段 3，2026-11-21，对照 `.spec/mockups/input-settings.html`）实际渲染与设计稿的偏差：

- 窗口顶栏与页标题：沿用现有设置窗口（680×620 pt），顶栏左侧显示当前页名（无衬线半粗体）、右侧排布全部 8 个页签；页面内不再重复衬线大标题，直接显示说明文字与内容区（设计稿为 760 px 宽、顶栏居中页签且页内带衬线 `<h3>` 标题）。
- 快捷键页：作用域筛选按命令模型补齐“分类”作用域（共 4 组：查看器、全局、列表、分类；设计稿仅列 3 组）；行尾恢复默认按钮仅在已改行显示，未改行留空对齐；冲突提示条使用 `Theme.dangerSoft` 圆角底色配 `Theme.danger` 文字、SF Symbols 警告图标与 `.mini` 原生“替换 / 取消”按钮；命令列表按注册顺序分组展示。
- 鼠标与触控板页：在 680 pt 宽窗口下采用单列纵向滚动布局（点击区域 → 滚轮 → 触控板 → 鼠标手势），避免双栏挤压截断；“全部恢复默认”放在页顶统一重置本页四类绑定。点击区域卡片使用自适应主题的 `Theme.well` 与等宽三列（设计稿为固定深色底且比例 `1:1.2:1`），默认命令标题为实际命令名“左侧一帧 / 无 / 右侧一帧”。滚轮先选行为模式（默认 / 缩放 / 执行命令 / 无），选“执行命令”后再展开“向上 / 向下”完整命令选择器。触控板按 `TrackpadInput` 模型提供横扫、轻点两下、旋转 3 项（不含上下轻扫，轻点两下默认“无”）。鼠标手势区常驻底部右键拖动录制区（不另设“＋ 录制手势”切换按钮），已有手势行支持直接经下拉框改绑命令。
- 菜单与工具栏页：“右键菜单 / 主菜单 / 工具栏”为互斥三段，切到“工具栏”分段才展示工具栏预览与“自定义工具栏…”主按钮（Slate 底配 Ivory 字，无查看器窗口时禁用并提示），不在菜单编辑页底部常驻工具栏预览。左侧菜单树用原生 `NSOutlineView` 渲染，带拖动手柄、SF Symbols 图标、分隔线标签与“动态”圆角徽章；右侧全部命令列表同步展示图标与“动态”徽章，支持拖拽或双击加入。
