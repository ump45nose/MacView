# MacView 需求规格

状态：需求澄清完成，2026-10-31 批准。

## Context

需要一个对标 NeeView 的 macOS 原生图片浏览器。此前 `Others/NeeView` 的 `feature/macos-port` 分支做过一次 .NET 10 + Avalonia 移植（151 个提交），记录的问题包括：Avalonia 无障碍查询导致内存持续增长、SMB 调用阻塞、本地 4K 首图约 355 ms。MacView 是全新项目，架构、布局和界面完全重新设计；NeeView 与移植版只在部分功能的实现上作参考。

本文经 11 轮追问确定范围、分层、关键决定和验收标准，是 Claude 与 Codex 跨 agent 开发的共同依据。架构设计与任务拆分写在后续文档中。

## 1. 定位与约束

- 技术路线：原生 Swift + AppKit，SwiftUI 用于次要界面；最低 macOS 27（两台设备均为 27.0.1）。
- 发布：自用 + 开源，不上架 App Store，不启用沙盒，ad-hoc 或 Developer ID 签名。P1 完成前只用本地 git；P1 完成后再建 `ump45nose/MacView` 公开仓库，许可证默认 MIT。
- 场景：写真图集速览、漫画/本子阅读、图视频混合素材三者为核心；网页图源为增量。
- 界面语言：简体中文 + 英文（String Catalog，默认中文）。
- 分工：
  - Claude：架构、需求、任务拆分，以及前端（AppKit/SwiftUI 界面、面板、查看器渲染（Metal/CALayer）、手势）。
  - Codex：其余全部，包括来源、压缩包、解码、缓存、调度、持久化、命令与设置模型、脚本/插件运行时。
  - 对接方式：两边以 Core 包中的 Swift 协议对接。
  - 执行流程：Codex 在项目内 `.worktree/<任务>` 的独立分支执行，每个阶段审核一次；后端能力由 Codex 自行验收，Claude 只审结论和方向。

## 2. 实测证据（2026-10-31，MacPro）

- 环境：macOS 27.0.1、Xcode 27.2、Swift 6.4.2；SDK 不含 libarchive 头文件。
- 网络：NAS fn（192.168.31.201）通过 SMB 3.1.1 挂载 10 个共享；本机走 Wi‑Fi 6（PHY 1020 Mbps），有一块闲置的 USB 千兆网卡。
- 样本：`/Volumes/Picture/YY/秀人` 为 3600×5400 的基线 JPEG，8–23 MB/张，没有内嵌 EXIF 缩略图。每个图集 70–90 张、600–740 MB，部分图集另有同名 `.gz`（128–224 MB）。
- 读取速度：单线程 11–16 MB/s，4 并发约 30 MB/s。吞吐随并发上升，说明瓶颈在单连接延迟。客户端已关闭强制签名，但服务端仍要求签名（AES_128_GMAC）；服务端没有报告支持命名流。
- 稳定性：测量途中部分目录枚举立即返回 `Operation timed out`，稍后恢复。与移植版的 MAC-NAS-004 属同类问题。
- 文件分布：Picture 共享（抽样 2 万个文件）有 jpg 7989、zip 1125、mp4 910、png 908、gz 630、webp 25、mov 16；Media 共享有 mkv；Book 共享以 txt 为主。
- 结论：缩略图和屏幕尺寸图都要读完整个文件。限制解码尺寸只能节省解码时间和内存，不减少网络读取；首次打开的速度 = 挂载吞吐 ÷ 文件大小。

## 3. 分层范围

### P0 基础骨架（高性能、符合使用习惯，为后续开发打基础）

框架：
- 统一来源抽象：覆盖文件系统和压缩包，插件数据源以后接入同一接口。
- 书与页模型。
- I/O 调度：支持优先级、取消和超时，主线程不访问文件系统。
- 解码与多级缓存：内存、缩略图、浏览图三级。
- 命令系统：菜单、快捷键、手势、脚本、插件都通过命令执行；绑定存为 JSON。
- 设置分层：书 > 路径规则 > 全局，局部优先。
- 停靠面板框架：左、右、底三个停靠区，每区可放多个面板（标签页或上下分割）；面板可拖到别的区、浮动成独立窗口，全屏时自动隐藏。
- 统一集合视图：列表、详情表格、网格、瀑布流四种样式可切换；每个面板单独设置缩略图尺寸和排序。
- 多主窗口 + macOS 原生标签页：每个窗口（标签）各开一本书，缓存全局共享；重启后恢复窗口和阅读位置。

功能：
- 文件夹、zip/cbz、tar、tar.gz 统一浏览；嵌套压缩包和压缩包内的子目录都能进入；gz 打开时流式解压到本地临时目录。
- 浏览方式：单页、双页（阅读方向、首页单页、宽页处理）、瀑布流、纵向连续（条漫）、横向连续（全景）。
- 子文件夹：默认作为下一本书；可按书或路径规则开启递归展开（可设深度）；只含一个子文件夹且没有图片的目录自动进入。
- 排序：文件名自然排序、修改时间、创建时间、大小、类型、随机、中文拼音；支持升降序，文件夹可在前也可混排。
- 缩放：原始尺寸、适合窗口、适合宽度、适合高度、填满裁切、仅缩小不放大、固定百分比、以光标为中心自由缩放、设备像素 1:1、放大镜、翻页保持缩放与位置。
- 重采样：Lanczos、最近邻、缩小后锐化。
- 大图：按屏幕需要的尺寸解码（上限可设）；放大超过上限时按需解码原图，超大图分块渲染。
- 缓存：
  - 缩略图和屏幕尺寸浏览图都持久化到本机 SSD；浏览图缓存有开关，两者各有容量上限，按 LRU 淘汰。
  - 预生成范围：当前书的全部页面（可见区域优先）、书架顺序中后 N 本书、当前目录各书的封面。
- 格式：ImageIO 原生支持的格式（JPEG/PNG/GIF/WebP/AVIF/HEIC/JXL/TIFF/RAW/PSD 合成图），含动图播放。
- 视频：用 AVFoundation 处理 mp4/mov/m4v，缩略图显示封面帧和时长，在查看器内播放。
- 面板：书架、页面列表。
- 每本书记住页码、单双页、方向、排序、缩放、浏览方式；可按路径规则设默认值。
- 默认快捷键；提供 P0 选项的设置窗口。
- NAS 访问：
  - 先走系统挂载路径。
  - 第一个任务：对比 SMB（关闭服务端签名、调整并发）和 NFS 的吞吐、延迟与枚举稳定性。
  - 若在系统挂载上解决延迟的复杂度明显高于内置 SMB 客户端（libsmb2），则改用内置 SMB。

### P1

- 书签、播放列表与历史：
  - 书签管书：记录文件夹、压缩包、数据源、网页的位置，支持多级文件夹，打开时从历史恢复页码。
  - 播放列表管页：跨书的具体图片/视频的有序集合，可建多个、拖拽排序，可当作虚拟书浏览。
  - 历史面板。
- 分类面板：目标文件夹（含自动列出子文件夹）、数字键移动/复制、新建目标并移入、移动/复制模式切换、撤销重做、NAS 安全移动。
- 文件操作：删除（本地文件移到废纸篓；NAS 上是永久删除，需二次确认）、重命名、复制图片/路径到剪贴板和拖出、在 Finder 中显示、用指定应用打开。
- 显示配置（即效果组）：
  - 内容：浏览方式、双页规则、方向、缩放模式、重采样、效果链、背景等。
  - 用法：可命名保存、快捷键切换，可绑定到书或路径规则。套用就是把值写入当前层级，不做引用联动。
  - 效果：基础调色（亮度、对比度、饱和度、伽马、色温、色调）。
- 脚本：JavaScript（JavaScriptCore），与 HTML 面板共用同一套应用 API，可挂事件，可绑到快捷键、菜单、手势。自定义命令：外部程序或 Shell 命令模板，支持文件路径等占位符。
- 插件：
  - 类型：命令与自动化、面板与页面（HTML/JS 自定义面板，用 WKWebView 承载）、数据源（WebDAV、在线图库 API 等）、格式解码与滤镜。
  - 运行：JS 插件跑在 JavaScriptCore/WKWebView，按清单声明权限；重活走外部进程（stdio JSON-RPC）。不支持进程内原生插件。
- 定制：
  - 菜单与工具栏：主菜单、右键菜单、工具栏的条目、顺序、快捷键可编辑。
  - 字体：面板、列表、信息叠加层、下拉菜单和右键菜单条目的字体可设。
  - 输入：快捷键（多键序列、冲突提示）、鼠标手势、触控板手势、点击区域与滚轮行为。
  - 窗口：隐藏标题栏/无边框、置顶、透明度、背景样式（纯色、棋盘格、毛玻璃、按图取色）、主题配色。
  - 布局方案：命名保存与切换。
- 搜索与元数据：文件名搜索（NAS 目录用浏览时积累的索引）、信息面板（EXIF、尺寸、文件信息）、评分与标签（写入文件元数据，不改写图片本身）。
- 画廊里的视频悬停拖动预览：按鼠标位置显示对应帧，帧进缓存。
- 用户数据一键导出/导入：设置、书签、播放列表、显示配置、布局、脚本插件。

### 增量

- 网页（复杂度高时可搁置）：用 WKWebView 做内嵌浏览标签或面板，含地址栏、前进后退、登录态保持、把网页图片当书打开、保存图片到目录；站点规则由插件提供。
- PDF 当书阅读、图片型 EPUB、HDR 高亮显示。
- AI 超分；色阶与曲线、锐化与降噪、风格滤镜。
- 等大网格、幻灯片。

### 不做

- 格式与功能：rar、7z、加密压缩包；mkv/webm 等系统不支持的视频；SVG；自动旋转适配。
- 平台与发布：完整浏览器（扩展、下载管理）、进程内原生插件、Susie 插件、实时跨设备同步、App Store 发布、NAS 端服务。
- 系统限制：菜单栏顶层标题的字体无法修改。

## 5. 性能与资源验收

随本规格于 2026-10-31 批准。实施中如有实测证据要求调整，更新本节并注明原因。

在 MacPro（M1 Pro、32 GB）上用秀人样本测：
- 本地 SSD：3600×5400 JPEG 在未预载时，首次显示 ≤ 150 ms；翻到已预载的页 ≤ 1 帧。
- 瀑布流滚动：主线程不做 I/O 和解码；ProMotion 120 Hz 下帧时间 P99 ≤ 8.3 ms；占位符按真实宽高比布局，图片加载完成时布局不跳动。
- NAS 首次浏览：缩略图生成吞吐 ≥ 同一挂载、同等并发下原始读取吞吐的 90%；滚动停止后 100 ms 内，可见项开始请求。
- 已缓存目录：重新打开后 100 ms 内显示首屏缩略图。
- 大目录：1 万项目录的枚举和排序不阻塞界面，内容渐进出现。
- NAS 异常：卡顿或断线时界面不冻结；I/O 超时 10 秒内显示错误状态并可重试；挂起的 NAS 调用不阻塞退出（≤ 3 秒）。
- 内存：解码缓存、缩略图内存缓存、浏览图预载各有预算，可配置；连续浏览 30 分钟后，常驻内存的波动 ≤ ±10%，无泄漏。

## 6. 默认决定

随本规格于 2026-10-31 批准，可按需调整。

- 最低系统版本为 macOS 27。
- 停靠面板属于各自窗口，新窗口套用默认布局；浮动面板全应用共享，作用于当前活动窗口。
- 效果作用于主视图的所有浏览方式，面板缩略图不加效果。
- 压缩包内的条目只读：不能删除、重命名、评分，但可以对压缩包本身操作。
- 评分和标签的具体格式（Finder 标签扩展属性，或 XMP 旁文件）在 P1 实测 SMB 扩展属性后确定。服务端没有报告支持命名流，扩展属性可能会退化成 `._` 文件。
- 设置与用户数据存放在 `~/Library/Application Support/MacView`（JSON，可手工编辑）；缓存存放在 `~/Library/Caches/MacView`。
