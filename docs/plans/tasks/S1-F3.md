# S1-F3 画布引擎正式版

前置：S0-F1。状态见 [roadmap](../roadmap.md)。

## 目标

在 S0-F1 验证过的“NSScrollView + 图层池”上，做出正式的画布引擎：四种布局、布局变化时保持锚点、向预取计划回报可见范围。连续模式、主区瀑布流和画廊面板都用它。

## 范围

- 引擎：
  - 从 `App/Debug/CanvasView.swift` 演进：图层池、可见区加余量的分配与回收、后台请求与取消。
  - 测试窗口改用正式引擎，继续作为回归工具。
- LayoutModel：
  - 砌体：列宽由缩略图尺寸决定，按列二分查找。
  - 网格：等大单元。
  - 纵向条、横向条：单列或单行；横向条的方向由阅读方向决定。
  - 只排已知宽高比的最长前缀（architecture.md §3.5“不跳动的排版”），后面的项到达后再追加，已排的项不移动。
- 锚点保持：
  - 宽度、缩略图尺寸或布局种类变化时，可见区顶部的项和它在视口中的相对位置保持不变。
  - 数据整体重排（排序变化）时，锚点取当前选中项，没有选中项时取可见区中心的项。
- 可见范围回报：滚动停止或可见项变化时回报项的范围与余量，去抖后交给 `ReaderSession.visibleRangeChanged` 或面板的预取计划；滚动停止后 100 ms 内可见项开始请求（requirements.md §5）。
- 图像：
  - 按项的像素尺寸请求，管线选择来源；先用已有的低质量结果占位，到达更高质量的再替换。
  - 只接受已解码、IOSurface 支撑的图像。
  - 每帧设置图层内容的数量有限额（默认 8，实测调整），超出的排到下一帧。
- 交互：点击、双击、选择（单选、⌘ 多选、⇧ 范围），键盘方向键移动选中项；捏合缩放改缩略图尺寸。
- 错误：单项加载失败时在图块上显示错误标记，可以重试。

## 不做

- 列表与详情表格（S2-F2，用 NSTableView）。
- 分页查看器（S2-F1）。

## 验收

- `make build test` 通过，零警告。布局模型和锚点计算有单元测试（纯计算，不依赖 AppKit 视图）。
- 四种布局下，1 万项用触控板真实滚动，在内建屏上用 Animation Hitches 录制，帧时间 P99 ≤ 8.3 ms。
- 用户拖动改窗口尺寸时，锚点项不离开视口；帧时间的数据写进报告。
- 宽高比陆续到达时，已经排好的项位置不变（测试中逐帧比较）。
- 滚动停止后 100 ms 内，可见项的请求已经发出（signpost 证据）。
- 自动场景的 App 侧统计不比 S0-F1 差：滚动更新 P99 ≤ 0.5 ms，全量重排 P99 ≤ 1 ms。
