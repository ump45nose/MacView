# S1-T7 MVSettings 与 MVCommands

前置：G0。状态见 [roadmap](../roadmap.md)。

## 目标

实现设置的存储、重载与分层解析，书记忆的持久化，以及命令系统的按键解析、P0 默认命令、默认绑定和菜单模型。

## 范围

### MVSettings

- JSON 文件（`~/Library/Application Support/MacView/`）：`settings.json`、`path-rules.json`、`keybindings.json`、`layout.json`。
  - 每个文件带 `version` 字段，原子写入（临时文件加改名）。
  - 外部编辑后自动重载：监听目录变化，去抖后重新解析，经 `changes()` 发出对应的 `SettingsChange`。
  - 解析失败时保留上一份可用的配置，发出 `fileError(file:message:)`，消息包含行列位置。
  - 文件不存在时用默认值，第一次修改时才写出。
- 通用的 JSON 文档存储（公开，供 App 存 `layout.json`）：按 Codable 类型读写、原子写入、外部修改通知、错误保留上一份。加入 §4。
- 分层解析：全局 ⊕ 匹配的路径规则（前缀越长越靠后）⊕ 书记忆，逐字段合并；全局层必须完整，缺字段时用默认值补齐并报告。
- 路径规则：按 `Location` 的根和层做前缀匹配，压缩包内的位置也能匹配。
- 书记忆：`state.sqlite`（GRDB.swift，与 S1-T4 共用依赖），按书的 Location 存取；写入批量合并。
- `updateGlobal` 写入 `settings.json` 并发出 `global` 变化。

### MVCommands

- BindingResolver：
  - 多键序列，序列超时默认 1 秒；等待后续按键时返回 `pending`，供界面显示待定提示。
  - 作用域：`textInput` 只匹配声明为该作用域的绑定；`viewer`、`list` 先匹配本作用域，再匹配 `global`。
  - 冲突检测：同一作用域中相同序列，或一个序列是另一个的前缀时，给出冲突列表（P1 的编辑器使用；P0 用于校验默认绑定和用户文件）。
- P0 默认命令（ID 与分类）：
  - 翻页：下一帧、上一帧、下一页、上一页、首页、末页、跳到指定页。
  - 书：下一本、上一本、打开文件夹或压缩包、在书架中显示当前书。
  - 浏览方式：分页、瀑布流、纵向连续、横向连续；单页/双页切换、阅读方向切换、首页单页、宽页策略。
  - 缩放：各缩放模式、放大、缩小、实际像素、设备像素 1:1、放大镜开关、翻页保持缩放。
  - 排序：各排序键、升降序、文件夹在前；递归展开开关。
  - 窗口与面板：新建窗口、新建标签页、全屏、显示/隐藏书架和页面列表、显示/隐藏停靠区。
  - 其他：重试失败的项、打开设置。
- 默认绑定参考 NeeView 的默认快捷键，并按 macOS 习惯调整（例如 ⌘ 组合、方向键、空格翻页、⌃⌘F 全屏）；`keybindings.json` 中的用户绑定覆盖同一命令的默认绑定。
- 默认菜单模型：由命令清单生成 P0 的菜单树（文件、显示、翻页、书、窗口），App 的 MenuBuilder 据此渲染。
- 命令标题用 `LocalizedStringResource`，中文为开发语言，英文翻译在 App 的 String Catalog 中补齐（S1-F1）。

## 不做

- 设置窗口和路径规则的编辑界面（S2-F3）。
- 菜单、绑定的编辑器和手势（S4）。

## 验收

- `make test` 通过，零警告。
- 设置：外部改写 `settings.json` 后 1 秒内发出变化；写入非法 JSON 时保留上一份配置并给出带行列号的错误；进程在写入时被 SIGKILL 后文件仍完整。
- 分层：全局、两条嵌套的路径规则和书记忆逐字段合并的结果正确；压缩包内的书能匹配外层目录的规则。
- 书记忆：1000 本书的写入和读取正确，重启后保持。
- 按键：两键序列在超时内匹配、超时后重置；`textInput` 作用域中单字母键不触发全局命令；默认绑定没有冲突。
- 每个默认命令都有标题、分类，并出现在默认菜单树或有默认绑定。
