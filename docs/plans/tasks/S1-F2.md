# S1-F2 停靠面板框架

前置：S1-F1。状态见 [roadmap](../roadmap.md)。

## 目标

实现左、右、底三个停靠区和浮动面板，面板可以在区之间拖动，布局按窗口持久化。书架、页面列表等具体面板在 S2-F2 装进来。

## 范围

- 结构：NSSplitView 分出左、中、右三栏，底部区在中间栏下方；中间是主视图。
- 面板栈：每个停靠区放一个面板栈，栈内的面板以标签页显示，或上下分割；可以折叠和调整尺寸。
- 面板协议：App 内的面板类型登记（标识、标题、图标、创建方法、视图设置的编解码），S2 的面板按此接入。
- 拖动：拖动面板的标签到另一个区、另一个栈或分割位置，拖动期间显示放置指示。
- 浮动面板：面板可以拖出成独立的 NSPanel；浮动面板全应用共享，作用于当前活动窗口，切换窗口时跟着切换内容来源。
- 全屏：全屏时停靠区自动隐藏，鼠标靠近对应边缘时浮出，离开后收回。
- 持久化：
  - 停靠布局和各面板的视图设置存入 `layout.json`，用 S1-T7 提供的 JSON 文档存储。
  - 新窗口套用默认布局；改动布局后去抖保存为新的默认布局。
  - 文件解析失败时用默认布局，并显示错误（S1-T7 的 `fileError`）。
- 命令：显示/隐藏各停靠区和各面板，登记到 CommandRegistry，出现在“显示”菜单。
- 视觉以设计稿为准，见 [docs/design/README.md](../../design/README.md) 的停靠相关画板。

## 不做

- 具体面板的内容（S2-F2）。
- 布局方案的命名保存与切换（S4-F3）。

## 验收

- `make build test` 通过，零警告。
- 用两个占位面板验证：拖到三个区的各个位置、标签页与上下分割互换、拖出浮动再拖回。
- 两个窗口各有自己的停靠布局；浮动面板切换活动窗口时跟随。
- 全屏时三个区隐藏，鼠标到边缘浮出；退出全屏后恢复原布局。
- 退出重启后布局恢复；手工改坏 `layout.json` 时窗口用默认布局打开并显示错误。
- 拖动面板和调整停靠区尺寸时，用 Animation Hitches 录一段：MacView 的帧时间 P99 ≤ 8.3 ms。
