# S1-F1 App 外壳

前置：G0（先接 Mock，S1-T8 完成后切到真实服务）。状态见 [roadmap](../roadmap.md)。

## 目标

搭起 App 的外壳：窗口与原生标签页、服务容器、由命令生成的菜单、按作用域路由的键盘输入和本地化。后续的停靠框架、查看器和集合视图都装在这个外壳上。

## 范围

- 生命周期：AppDelegate 负责启动服务容器、打开第一个窗口、退出时调用 `CoreServices.shutdown()`（有时限）。
- 服务容器：Debug 构建中 `-MVMockServices YES` 用 `CoreServices.makeMock`；否则用 `CoreServices.make`，S1-T8 完成之前回落到 Mock 并在窗口中标明。创建失败时显示错误窗口，不静默回落。
- 窗口：
  - 每个窗口或标签一个 `ReaderWindowController`，持有自己的 `ReaderSession`。
  - `tabbingMode = .preferred`；新建窗口、新建标签页、合并窗口、移动标签页到新窗口都可用。
  - 窗口内容先放一个最简的页面视图：显示当前页帧的图像，能翻页、切书，验证会话接入；正式查看器是 S2-F1。
  - 打开文件夹或压缩包：打开面板、拖放到窗口和 Dock 图标，经 `SourceRegistry.location(for:)` 转成 Location。
- MenuBuilder：
  - 把 Core 的默认菜单模型渲染成 NSMenu，加上系统菜单项（关于、服务、隐藏、退出、窗口列表）。
  - 菜单项的启用状态来自 `CommandRegistry.isEnabled`，单键绑定显示为菜单项的快捷键；按键由 InputRouter 处理时不重复触发。
  - 取代现有的手写 `MainMenu`；Debug 菜单保留。
- InputRouter：
  - 文本框、弹出层和菜单先在响应链中处理按键；未处理的按键转成 `KeyChord`，连同当前作用域交给 BindingResolver。
  - 作用域由第一响应者决定：文本输入为 `textInput`，列表为 `list`，查看器为 `viewer`，其余为 `global`。
  - 多键序列等待时，在窗口底部显示待定提示，超时或匹配后消失。
- App 侧的命令处理器：新建窗口、新建标签页、全屏、打开、关闭等界面命令登记到 CommandRegistry。
- 本地化：String Catalog，开发语言为简体中文，补齐英文；Core 命令标题的英文也在这里。
- 视觉以设计稿为准：窗口外观、标题栏与工具栏布局，见 [docs/design/README.md](../../design/README.md)。

## 验收

- `make build test` 通过，零警告。
- 菜单由命令清单生成，快捷键显示正确；切换系统语言到英文后菜单和窗口文字都是英文。
- 在文本框中输入字母和方向键不触发翻页或切书；查看器中方向键翻页；两键序列显示待定提示。
- 在 Mock 上打开一本 100 页的书，翻页和切书正常；多个标签页各自独立翻页。
- 打开面板和拖放都能打开文件夹与 zip（S1-T8 之后用真实服务验证）。
