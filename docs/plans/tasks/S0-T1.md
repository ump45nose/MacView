# S0-T1 工程脚手架

前置：无。状态见 [roadmap](../roadmap.md)。

## 目标

搭一个能构建、能测试的空骨架，作为所有后续任务的起点。

## 范围

- 工具：用 Homebrew 安装 XcodeGen（本机当前没有）。`make project` 先检查 `xcodegen` 是否存在，缺失时提示安装命令。
- `project.yml`，定义 app target `MacView`：
  - 基本设置：macOS 27、Swift 6、bundle id `io.github.ump45nose.MacView`、显示名 MacView、源码目录 `App/`。
  - 签名与沙盒：不启用沙盒，本地 ad-hoc 签名（`CODE_SIGN_IDENTITY = "-"`）。
  - 依赖本地包 `Packages/MacViewKit`，链接 App 需要的各个 library product，包括 MVTestSupport（Debug 构建可以用 `-MVMockServices YES` 切换到 Mock）。
- `Packages/MacViewKit/Package.swift`：
  - 平台 `.macOS("27.0")`，Swift 6 语言模式。
  - library target：MVFoundation、MVIO、MVArchive、MVMedia、MVCache、MVPipeline、MVSettings、MVCommands、MVReading、MVServices、MVTestSupport。
    - 依赖关系按 [architecture.md](../../architecture.md) §2。
    - 每个模块对应一个 library product 和一个测试 target（`<模块>Tests`）。
    - 各模块只放占位文件，不写实现。
  - executable target `mvbench`。
- mvbench 框架：
  - 子命令登记机制，后续任务往里添加 `io`、`fixtures` 等子命令。
  - `mvbench env` 采集以下信息：
    - 机型、芯片、内存、系统版本。
    - 网络接口：类型、速率。
    - 指定路径所在卷的挂载来源和文件系统类型。
  - 公共测量工具：
    - 多次重复测量。
    - 统计 P50/P95/P99 与均值。
    - 把结果以 JSON 输出到指定文件。
- `Makefile`：
  - 目标：`project`、`build`、`test`、`bench`、`run`、`clean`。
  - `test` 运行全部测试。
  - `bench` 用 release 构建 mvbench，并原样传入参数。
- `.gitignore`：`.worktree/`、`*.xcodeproj`、`build/`、`DerivedData/`、`.build/`、`.swiftpm/`、`Fixtures/local/`、`.DS_Store`。
- App 最小骨架：AppDelegate 启动、一个空主窗口、启用原生标签页、系统默认菜单栏。只为让 target 能构建运行，S1-F1 会重写。
- MVFoundation：
  - 日志 subsystem：`io.github.ump45nose.MacView`。
  - signpost 分类常量：io、decode、cache、layout、render。

## 不做

- App 的界面功能：S1-F1。
- CI：S6。
- 引入第三方依赖。

## 验收

- 在新的 worktree 上依次运行 `make project`、`make build`、`make test`，全部成功且零警告。
- `make run` 能启动 App 并显示空主窗口；新建的窗口可以合并为标签页。
- `mvbench env` 输出合法的 JSON，字段齐全。
- `git status` 中看不到生成的工程和构建产物。
