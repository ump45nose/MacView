# S0-F1 画布引擎技术验证

前置：S0-T4。状态见 [roadmap](../roadmap.md)。

## 目标

在 Mock 上验证“NSScrollView + 图层池”的方案，能否让 1 万项的瀑布流在 120 Hz 下流畅滚动。结论决定 S1-F3 的实现路线。

## 范围

- 在 `App/` 中建一个只在 Debug 构建中可用的测试窗口：
  - 1 万项的砌体布局。
  - 数据来自 MockImagePipeline，合成缩略图延迟到达。
- 图层分配：
  - 只为可见区加余量内的项分配图层，滚动时复用。
  - 布局计算与图像准备都不在主线程上做 I/O 或解码。
- 测试场景：快速拖动、惯性滚动、改变窗口尺寸引起的重新排版。

## 不做

- 四种 LayoutModel、锚点保持等正式功能（S1-F3）。
- 真实图片与真实管线。

## 验收

- 在 MacPro 内建的 ProMotion 屏幕上用 Instruments（Animation Hitches）录制，帧时间 P99 ≤ 8.3 ms。
- 图层数量随可见区变化，有上界，不随总项数增长。
- 如果达不到，在报告中给出瓶颈和替代方案，并在 S1-F3 之前更新 architecture.md §3.8。
